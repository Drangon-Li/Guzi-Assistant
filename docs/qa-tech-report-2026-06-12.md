# al1 原型多视角模拟测试技术报告

日期：2026-06-12｜版本：commit `d0d53c4` 起测，修复后版本见本报告末尾

## 1. 测试方法

三个并行 Agent 模拟不同用户以不同深度使用产品：

| Agent | 模拟角色 | 方式 | 覆盖 |
|---|---|---|---|
| A1 | 大学生轻度用户（首次使用） | CDP 真实驱动运行中的应用（puppeteer-core 接 9222 调试端口），10 步完整剧本 | 清数据→向导→提交解析→卡片操作→时间轴→详情编辑→日程→设置→重复提交；38 张过程截图存 `test/agent-shots/` |
| A2 | 职场新人重度用户 | 直连解析 API 跑 14 个真实风格用例（脚本 `test/agent-tmp/run-eval.mjs`） | 长邮件、会议邀请、三种归属方式、相对时间大全、跨年、英文、稳定性双跑、闲聊、敏感内容、模糊请求、时间矛盾、5197 字长纪要 |
| A3 | 挑剔的安全敏感用户 | 逐文件代码审查 + 纯逻辑边界实测（3 组脚本实跑 parsing/sensitive/labels） | 竞态、IPC 面、错误处理、数据层、隐私、UI 状态机 |

## 2. 解析质量基线（A2 实测）

- 延迟：min 2.4s / median 12.4s / max 18.9s（n=14）
- 时间解析：今天下班前→18:00、明早10点、下周三、这周内、本月底、端午节前、明年1月5日、EOD Wednesday、全天事项——全部正确
- 归属判断：点名（姓名/昵称/账号/邮箱收件人）→ yes 0.93~0.98；角色泛指（"产品同学谁有空"）→ uncertain 0.65 confirm；部门泛指 → uncertain；全部符合规则
- 稳定性：同一输入两次提交，除 belonging_reason 措辞外字段完全一致
- 长文：5197 字纪要中只提取点名给用户的 2 项，无幻觉
- 时间矛盾（正文日期 vs 星期不符）：以显式日期为准，处理合理

## 4. 已知未修（需决策或留生产版）

1. **时间轴顶部"全部倒计时"与下方分组重复展示**——A1/A3 均判为问题，但"显示所有日程的倒计时"是产品方 6/11 的明确要求，与测试结论冲突，**待产品方裁决**（备选：只置顶 ≤3 天紧急项 + "展开全部"）。
2. IPC 深度加固（preload 通道白名单、capture:files 路径来源校验）——生产版必做，原型风险可控（React 全程转义 + CSP，无 XSS 通路）。
3. API key 明文落库且全量回传渲染层——生产版改 safeStorage + 脱敏回显。
4. 纯开始时间的过期任务（开过的会）缺"已结束"归档语义，永远留在"全部未完成"。
5. 解析延迟 median 12.4s——已有加载态兜底，后续可考虑低延迟模型档位或流式反馈。
6. 右键"快速操作"+ 托盘拖拽提交（前轮已提议，未拍板）。
