# 桌宠对话框 + 拖文件总结（分两期）

日期：2026-06-24　分支：`feat/desktop-pet`

## 目标

1. 点桌宠 → 在它旁边弹一个气泡感的可交互对话框（不再开主窗口）。
2. 通过对话框跟桌宠聊天：新建任务、询问当前任务。
3. 把文件拖到桌宠上 → 桌宠做总结 + 找出"属于用户的日程"，在对话框里反馈、确认入库。

## 现状（探索结论）

- 助手对话后端已存在：`assistant:chat`（多轮 LLM）/`assistant:add`（确认入库），prompt 已内置当前任务，能答"今天有啥/哪个紧急"。新建/查询任务**已支持**。
- 对话 UI 已存在：`AssistantChat`（被 `FloatingAssistant` 包在主窗口右下角弹）。
- 文件抽取已存在：`captureFiles` → `extractFromFile`（png/jpg/pdf/docx/txt）→ `parseToItems`（LLM，含 belonging 归属判断）。
- 缺：①桌宠旁的对话窗口 ②点桌宠开它 ③拖文件到桌宠 ④对文件做"总结"（无现成 summarize）。

## 架构决策

对话框 = **一个独立无边框透明置顶小窗口，加载同一个 React 渲染层（hash `#/petchat`）**，只渲染聊天部分（气泡卡片），定位到桌宠旁。
理由：复用 `AssistantChat` 全部功能与后端；独立窗口可获键盘焦点打字；避免把 React 塞进手写的桌宠 HTML（且 Electron 窗口会裁剪超出边界的内容，DOM 飘不出窗口）。

## 期 1：点桌宠 → 旁边气泡对话框

改动：
1. `src/main/windows.ts`：导出 `rendererPreload`（preload 路径）和 `loadRendererRoute(win, hash)`（原内部 `load`），供新窗口复用 dev/prod 加载逻辑。
2. `src/main/pet/pet-chat-window.ts`（新）：
   - 无边框/透明/`alwaysOnTop('screen-saver')`/`skipTaskbar`/`hasShadow:false`，约 380×520，`preload: rendererPreload`，懒创建，加载 `#/petchat`。
   - `showPetChat()`：定位到桌宠左侧（放不下→右侧），用 `getDisplayNearestPoint` 夹进 workArea；`show()+focus()` 可打字。
   - `hidePetChat()` / `isPetChatVisible()` / `togglePetChat()`。
   - `blur` 自动收起；`togglePetChat` 用 250ms 守卫消除"点桌宠失焦先 hide 再 toggle 重开"的竞态。
   - 独立监听 `openpets:pet-drag-start` → 拖桌宠时收起对话框（解耦，不反向 import pet-window）。
3. `src/main/index.ts`：点桌宠 `onClick` 由 `focusMain('assistant')` 改为 `togglePetChat()`。
4. IPC：`ipc-channels.ts` 加 `pet:chat-hide`；`ipc.ts` 加 `ipcMain.handle('pet:chat-hide', () => hidePetChat())`；`api.ts` 加 `petChatHide`。
5. 渲染层：`App.tsx` 加 `#/petchat → <PetChat/>`；新建 `src/renderer/src/pages/PetChat.tsx`：透明窗口里一张圆角气泡卡，头部（头像+名+✕），主体 `AssistantChat`，自取 profile/tasks/settings，Esc/✕ 调 `api.petChatHide()`，订阅 `eshell:tasks-updated` 刷新。

复用不改：`assistant:chat`/`assistant:add`/`tasks:*`/候选确认流程。

期 1 验收：点桌宠 → 旁边弹气泡聊天 → 问"今天有啥日程"、说"建个明天3点的会" → 候选确认入库。

## 期 2：拖文件到桌宠 → 总结 + 抽日程（在对话框里回）

改动（期 1 完成后再做）：
1. `resources/pet/pet-preload.cjs`：加 `dragover`/`drop`，发 `openpets:pet-drop-files`；拖入桌宠高亮反馈。
2. 主进程：drop → `extractFromFile()` 取文本 → 打开对话框 → 把文本走 `assistant:chat`，让助手回"一句总结 + 可能属于你的日程候选" → 对话框里确认入库。
3. 助手 prompt 微调：处理文件输入时先给一句总结（基本不必单独写 summarize）。

期 2 验收：从 Finder 拖 PDF/截图到桌宠 → 对话框"总结:…；发现这些可能是你的日程:…" → 确认入库。

## 非目标 / 风险

- 对话框为独立渲染窗口 = 独立会话上下文（与主窗口助手各自历史），可接受。
- 点桌宠开窗会抢焦点（为打字），是用户主动点击，符合预期。
- v1 对话框开时定位一次；拖桌宠即收起（不做实时跟随）。
- 多文件批量总结、对话框跟随桌宠移动：暂不做。
- 主窗口原有助手保留不动。
