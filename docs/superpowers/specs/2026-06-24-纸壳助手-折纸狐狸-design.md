# 纸壳助手视觉重设计：折纸狐狸（SVG 程序化）

日期：2026-06-24　分支：`feat/desktop-pet`

> **修订 2（2026-06-24，已落地）**：折纸狐狸观感不佳，弃用。改为**用品牌标 `brand-logo.png` 裁出的橙色 mark（`resources/pet/pet-mark.png`）做静态桌宠**，并删除全部动画/运动引擎/反应→动画映射/反应覆盖等"不必要组件"。
> 保留：透明置顶窗口、点击开助手、手动拖拽、缩放/暂停/显隐、**事件气泡通知**（M5 联动：日程/任务完成等仍弹气泡）。
> 下文"折纸狐狸 + 9 状态动画"部分为历史方案，已不代表当前实现。

## 背景与动机

当前桌宠"纸壳助手"在代码里叫这个名，但视觉上直接搬用了 openpets 的猫头鹰雪碧图
（`resources/pet/default-pet-spritesheet.webp`，Professor Hoot）。"名字叫纸壳、长得是猫头鹰"
与产品调性不符。本次把视觉换成 **折纸狐狸**，并用 **SVG + CSS 程序化绘制/动画** 取代雪碧图，
直接替换猫头鹰（不保留双宠）。

决策（用户已确认）：
- 视觉方向：折纸 / 剪纸风
- 角色：折纸狐狸（有脸、能演表情、折纸语言强）
- 配色：角色本色（狐狸橙）+ 牛皮纸点缀
- 美术来源：代码画 SVG + CSS，端到端实现，无外部美术资源
- 范围：直接替换猫头鹰

## 核心思路：外科手术式替换

读 `src/main/pet/` 代码后确认：**整套状态机不需要改**，只换"画什么 + 怎么动"。

保留不变（决定低风险）：
- `data-reaction-state` / `data-motion-state` 属性驱动机制（`reaction-mapping.ts` + preload）
- 11 reaction → 9 状态映射（`defaultReactionToSpriteState`）
- IPC 通道 + preload 的 9 状态名校验（`pet-preload.cjs`）
- 设置页反应覆盖 UI（`selectableAnimationMetadata`，7 个可选状态）
- 窗口创建 / 拖拽 / 点击穿透 / 气泡 / 缩放 / 暂停 / 运动发布

替换掉：
- `.sprite` 背景图 → 内联 `<svg>` 折纸狐狸
- `background-position` steps 动画 → 每状态 CSS `@keyframes` 变换
- `default-pet-spritesheet.webp` → 删除
- `defaultPetSprite.states` sprite 行表 → SVG 动画时长表

狐狸沿用猫头鹰那 **9 个状态名**（`UniversalSpriteState`），同一状态名现在播一段 SVG 动画，
而非切雪碧图帧。因此 reaction 系统、设置页、M5 事件联动全部原样工作。

## 角色与配色

- `viewBox="0 0 192 208"`（与现尺寸一致，窗口/缩放/hitbox 计算不变）
- 扁平多边形 + 双色折面 + 牛皮纸阴影色，呈折纸质感
- SVG 分组（带 class，供 CSS 变换 / transform-origin）：
  `.fox-tail` `.fox-body` `.fox-head` `.fox-ear-l` `.fox-ear-r` `.fox-eyes` `.fox-mouth` `.fox-arm`
- 配色：狐狸橙 `#f2a65a → #e08a3c`；阴影/折痕牛皮纸色 `#b9622c`；腹部/雪地米白 `#fbe9d2`；眼/线 `#2b2b2b`

## 动画状态清单（"一系列连串动画"）

9 个状态全部 CSS keyframes 程序化：

| 状态 | 对应 reaction | 动画 | 循环 |
|---|---|---|---|
| `idle` | idle | 呼吸 scaleY 1↔1.02 + 尾巴慢摆 + 偶尔眨眼 | ∞ |
| `review` | thinking | 头微歪 + 眼上看/抬眉 + 慢点头 | ∞ |
| `running` | working/editing/running | 快速上下 bob + 耳朵抖 + 尾巴快摇 | ∞ |
| `waiting` | testing/waiting | 左右轻晃 + 尾巴下垂 | ∞ |
| `waving` | waving | 一爪抬起挥手 + 头晃 + 弯笑眼 | 2× |
| `jumping` | success/celebrating | 起跳 translateY + 挤压拉伸 + 耳立 + ^_^ 眼 | 2× |
| `failed` | error | 左右抖 translateX + 耳耷 + X 眼/垂眼 | 2× |
| `running-right` | 拖动向右 | 前倾 + 快 bob + 尾后扬 | ∞ |
| `running-left` | 拖动向左 | 同上镜像 `scaleX(-1)` | ∞ |

运动态（run-left/right）CSS 源序排在反应态之后 → 拖动时盖过反应动画，松手回反应态
（与现状级联一致，由 `spriteStateCss()` 等价物的输出顺序保证）。

## 表情层

狐狸有脸，五官随 reaction 切换（同一套 `data-reaction-state` 选择器切换眼/嘴形状）：
- idle：普通点眼 + 偶尔眨
- thinking：半眯上看
- success/celebrating：弯月笑眼
- error：X 眼 / 垂眼
- waving：友好张眼

雪碧图给不了的细腻反馈，近零额外成本。
