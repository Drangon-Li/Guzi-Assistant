# 交互捕获决策验证（interaction capture）

#路线图 2a/2b：监控敏感按键（回车/空格），回车时把「当前输入内容」作为被动记忆来源记录 —— 但不是每个回车都记。本 eval 验证**纯决策算法** `src/shared/interaction-capture.ts`：给定内容 + 近期已记录状态，判断是否值得记录。

## 跑

```bash
node eval/interaction/run.mjs   # 纯逻辑，无 API，无账号
```

## 决策规则（不过度：宁漏勿错，护凭据）

- 太短（<6）/ 无实质文本（纯标点/数字/emoji）→ 跳过
- 疑似凭据（无空格、8~64 长、英文数字符号混合 ≥3 类、无中文）→ 跳过（与解析层护凭据一致）
- 寒暄/语气词（ok/哈哈/收到/谢谢…）→ 跳过
- 近期重复（同内容 10 分钟内）→ 跳过
- 其余有实质内容 → 记录

## 基线结果（2026-06-15）

**15/15 通过**（14 标注样本 + 1 去重场景：同内容首次记、窗口内重复跳过、窗口外又可记）。
